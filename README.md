# POO Project

Projet d'exemple de création d'un Framework complet sans utilisation de l'outil `composer`.
Le but est de reproduire le plus possible ce qui fait la force des frameworks. Voici des exemples :

- Un Dependency Injection Container (DIC)
- Une CLI pour lancer des commandes (ex : `php artisan` ou `php bin/console`)
- Un système de migration pour la BDD
- Un routing applicatif avec des middlewares
- Un système de Queue pour lancer d'autre processus sans impacter la requête HTTP
